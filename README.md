# Roolipeli

Roolipeli sovellus jossa voi tehdä kampanioita ja hahmoja.

## Tekijät

- Elias Niemi
- Farid Hasanzade
- Pavel Lange

## Sovelluksesta

D&D-tyyppinen verkkosovellus, jossa käyttäjä voi rekisteröityä, kirjautua sisään, luoda hahmoja ja kampanjoita sekä muokata ja poistaa niitä.

Sovellus on tarkoitettu henkilöille, jotka tykkäävät roolipeleistä.

## Ominaisuudet

- Käyttäjän rekisteröityminen
- Kirjautuminen
- Profiilin poistaminen
- Kampanjoiden luominen
- Kampanjoiden muokaminen
- Kampanjoiden poistaminen
- Hahmojen luominen
- Hahmojen päivittäminen
- Hahmojen tarkastelu
- Hahmojen muokaminen
- Hahmojen poistaminen
- Hahmojen lisääminen/poistaminen kampanjoihin/sta
- NPC:n luominen ja poistaminen
- Esineiden luominen ja poistaminen
- Esineiden antaminen hahmoille
- Kutsuminen kampanjaan
- Hyväksytyt/hylätyt kutsut
- Antaa hahmoille statuksia
- Hahmojen ja kampanjoiden kuvien lisääminen

## Asennus - ??? 

Ohjeet projektin asentamiseen.

1. Kloonaa repository
2. Luo tietokanta
3. Muuta db.php tiedostossa tiedot kuten tietokannan nimi ja salasana omaksi.
4. Avaa konsoli ja kirjoita php -S localhost:8888
   
## Tietokanta

Tietokannassa on kaikki käyttäjät, hahmot, kampanjat, kutsut, NPCT.

Miten tietokanta luodaan?
Tietokanta luodaan tekemällä table:ja joihin lisää rivejä kuten ID, nimi jne..
Onko mukana SQL-tiedosto?
Mukana ei ole SQL-tiedostoa

## Konfiguraatio

Mitä asetuksia käyttäjän pitää muuttaa ennen käynnistämistä?
Käyttäjän pitää muuttaa tietokannan käyttäjätunnus, salasana, server nimi ja tietokannan nimi


## Käynnistäminen

Miten sovellus käynnistetään paikallisesti?
Sovellus käynnistetään kirjoittamalla konsoliin php -S localhost:8888.
